# Los Abuelitos Atlixco

Landing de Palapa y Cabañas Los Abuelitos (Atlixco, Puebla). Next.js + Tailwind, exportada como sitio estático.

Sitio: https://abdalotaa.github.io/los-abuelitos/

## Desarrollo

```bash
npm install
npm run dev
```

## Publicación

Cada push a `main` construye el sitio y lo publica en GitHub Pages con `.github/workflows/pages.yml`.

Los datos de contacto están en `lib/contacto.ts` y las fotos en `public/fotos/`.
